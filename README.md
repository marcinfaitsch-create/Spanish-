# ¡Hola! – Spanisch für Anfänger 🇪🇸

Eine kleine Lern-App fürs iPhone (Web-App), gehostet über GitHub Pages.

## Funktionen
- 9 Themen mit über 100 Wörtern und Sätzen
- Karteikarten mit Umdreh-Animation
- Übungen: Multiple Choice, Hörverständnis und Schreiben
- Spanische Aussprache per Lautsprecher-Button
- XP, Tagesziel und 🔥 Streak
- Lernsystem: schwierige Wörter kommen öfter dran
- Funktioniert offline, Fortschritt bleibt auf dem Handy gespeichert

## Auf GitHub veröffentlichen
1. Auf github.com ein neues Repository anlegen, z. B. `hola-spanisch` (Public).
2. „uploading an existing file“ anklicken und **alle Dateien** aus diesem Ordner hochladen → „Commit changes“.
3. Im Repo: **Settings → Pages** → bei „Branch“ `main` und `/ (root)` wählen → **Save**.
4. Nach 1–2 Minuten ist die App erreichbar unter:
   `https://DEIN-NAME.github.io/hola-spanisch/`

## Aufs iPhone holen
1. Den Link in **Safari** öffnen.
2. Unten auf **Teilen** (Quadrat mit Pfeil) tippen.
3. **„Zum Home-Bildschirm“** wählen → Hinzufügen.

Fertig – die App startet jetzt im Vollbild mit eigenem Icon. 🎉

> Tipp: Wenn du keinen Ton hörst, steht der Stummschalter am iPhone wahrscheinlich auf lautlos.
